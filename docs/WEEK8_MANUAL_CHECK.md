# Android에서 Guided/Required 검증하기

기존 PC의 `.env`를 유지하고 `flutter pub get` 후 Android 에뮬레이터/실기기로 `flutter run -d <id>`를 실행한다. 네이티브 플러그인이 추가됐으므로 기존 실행은 완전히 종료하고 재실행한다. Android 최소 API는 secure storage 패키지가 요구하는 23 이상이어야 하며 앱은 Flutter의 더 높은 기본값을 따른다. Android 백업은 비활성화했고, iOS에는 Keychain entitlement를 추가했다. iOS 실행·서명 검증은 별도로 필요하다.

## A. 로그인과 내 정보

- [ ] 토큰이 없는 최초 실행: 스플래시 이후 로그인 화면.
- [ ] 틀린 로그인: Form 오류만 표시, 만료 Snackbar 없음.
- [ ] 올바른 로그인: 홈 진입 → 마이페이지에서 GET me의 이메일·닉네임 확인.
- [ ] 어떤 탭으로 진입하든 내 정보가 로드됨.
- [ ] 앱을 완전히 종료하고 다시 실행: 스플래시에서 토큰 읽기·GET me 검증 후 홈. 로그인 화면이 잠깐 노출되지 않음.
- [ ] 복원 중 네트워크 차단: 재시도 화면 유지, 토큰 유지. 복구 후 다시 시도로 홈 진입.

## B. 프로필 수정

- [ ] 프로필 수정 화면은 하단 탭이 없고 이메일은 읽기 전용.
- [ ] 닉네임 한 글자: 2~12자 필드 오류.
- [ ] 새 닉네임 저장: 마이페이지에 즉시 반영.
- [ ] 본인이 만든 다른 계정의 닉네임: MEMBER409_1과 입력 유지.
- [ ] 저장 전 네트워크 차단: 입력 유지·재시도 안내, 로그인 유지.
- [ ] 현재 닉네임 그대로 저장: PATCH 없이 완료.

## C. v7 평점

- [ ] 영화 상세에서 실제 TMDB 영화 ID로 별점·코멘트 등록. memberId를 path/body/query에 넣지 않음.
- [ ] POST 201 result의 Rating으로 카드가 생성됨.
- [ ] 마이 → 이번 로그인에서 등록한 평점에서 수정: 기존 별점·코멘트 초기값, PATCH 200 result로 갱신.
- [ ] 코멘트를 유지해 저장하면 유지, 비워 저장하면 null로 지워짐.
- [ ] 삭제 취소는 API 없음. 삭제 확인은 DELETE 200 wrapper/result=null이며 카드 제거.
- [ ] 중복 등록 409: 입력 유지·Snackbar, 로그인 유지.
- [ ] 403은 가상 응답 테스트 또는 본인 테스트 계정 두 개로만 확인. 로그아웃되지 않음.

## D. 로그아웃·만료·전환

- [ ] 마이 앱바 로그아웃: /login 이동, member·현재 평점·저장 토큰 제거. 만료 Snackbar 없음.
- [ ] 뒤로가기나 보호 경로 직접 진입으로 이전 계정 화면에 돌아갈 수 없음.
- [ ] 다른 계정 로그인: 이전 세션 평점이 보이지 않음.
- [ ] 보호 API의 AUTH401_2/3/4: 로그인 화면으로 이동, 만료 안내 한 번.
- [ ] 동시 401·이전 세션의 늦은 응답: 새 계정이 로그아웃되지 않음(자동 테스트로 재현 가능).

실제 만료는 서버의 토큰 유효시간을 기준으로 확인한다. 임의로 JWT 내용을 바꾸면 서명 무효 AUTH401_3 검증이지 시간 만료 AUTH401_4 검증이 아니다. 가상 응답 테스트와 실서버 촬영을 구분한다.

## Android secure storage 확인

1. 실제 사용한 Android 기기명·API 레벨을 기록한다.
2. 로그인 성공 후 앱 완전 종료·재실행으로 세션 복원을 확인한다.
3. 로그아웃 후 다시 완전 종료·재실행해 로그인 화면에 남는지 확인한다.
4. 앱이 백그라운드였다가 돌아온 것과 프로세스 재시작을 구분한다.
5. JWT 원문을 화면에 표시하거나 기기 저장소에서 추출해 캡처하지 않는다. 저장소의 write/read/delete 호출 계약은 테스트로, 실제 플랫폼 동작은 위 흐름으로 확인한다.

## 촬영·제출

Android Studio Running Devices의 녹화 또는 기기 화면 녹화를 사용한다. 비밀번호 입력과 JWT/Authorization 값은 촬영에서 제외한다. Network Inspector를 캡처한다면 민감 필드가 가려진 상태에서 method/path/status/code만 남긴다.

추천 영상: `01-login-me`, `02-restart-restore`, `03-profile-update-409`, `04-v7-rating-crud`, `05-expiry-logout`.

로그인 복원은 되더라도 이전 내 평점 전체 목록은 비어 있는 것이 이 구현의 정상 동작이다. 서버의 평점이 삭제된 것으로 기록하지 않는다.
